Cash Pilot

Sistema de gerenciamento financeiro com arquitetura full stack.

Angular Spring Boot JWT PostgreSQL

Propósito do Projeto

O Cash Pilot é uma aplicação web full stack desenvolvida para gerenciamento financeiro pessoal, com foco em organização, controle de gastos e segurança dos dados do usuário.

A aplicação utiliza uma arquitetura desacoplada, com backend em Spring Boot responsável pela exposição de uma API REST segura, e frontend em Angular consumindo esses dados de forma dinâmica.

O sistema implementa autenticação baseada em JWT, garantindo controle de acesso às rotas e proteção das informações do usuário, seguindo boas práticas utilizadas em aplicações reais de mercado.

Funcionalidades Chave

  • Autenticação de usuários com JWT
  • Login seguro com validação de credenciais
  • Proteção de rotas no frontend com Auth Guard
  • Interceptação automática de requisições HTTP com token
  • Integração completa entre frontend (Angular) e backend (Spring Boot)
  • Estrutura preparada para expansão de funcionalidades financeiras

Tecnologias Utilizadas

  • Java (Spring Boot)
  • Spring Security + JWT
  • Angular (Standalone Components)
  • REST API
  • PostgreSQL
  • Git
