Cash Pilot

Sistema de gerenciamento de finanças pessoais com arquitetura full stack.

Angular Spring Boot JWT PostgreSQL Tailwind CSS Railway Vercel

Propósito do Projeto

O Cash Pilot é uma aplicação web full stack desenvolvida para gerenciamento de finanças pessoais, com foco em controle de receitas, despesas e saldo em tempo real.

A arquitetura é desacoplada: o backend em Spring Boot expõe uma API REST segura hospedada no Railway, enquanto o frontend em Angular consome esses dados de forma reativa, hospedado no Vercel.

O sistema implementa autenticação baseada em JWT com Spring Security, garantindo controle de acesso às rotas e proteção das informações do usuário, seguindo boas práticas utilizadas em aplicações reais de mercado.

Funcionalidades

  • Cadastro e autenticação de usuários com JWT
  • Login seguro com validação de credenciais e BCrypt
  • CRUD completo de transações financeiras
  • Classificação por tipo: Receita (INCOME) e Despesa (EXPENSE)
  • Transações seperadas por mês
  • Resumo financeiro: total de receitas, despesas e saldo
  • Proteção de rotas no frontend com Auth Guard
  • Interceptação automática de requisições HTTP com token JWT
  • Feedback visual com toast notifications
  • Tratamento global de erros HTTP com interceptor
  • Documentação interativa da API com Swagger UI
  • Deploy completo em nuvem (Railway + Vercel)

Arquitetura

O backend segue o padrão de camadas Controller → Service → Repository, com DTOs para transferência de dados e separação clara de responsabilidades. O frontend é organizado em features, core e shared, com serviços isolados, interceptors globais e signals para gerenciamento de estado reativo.
