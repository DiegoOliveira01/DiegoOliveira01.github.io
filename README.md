## 🚀 Projetos em Destaque

### 💰 Cash Pilot
Sistema completo de gerenciamento de finanças pessoais com arquitetura full stack desacoplada.
Backend em Spring Boot (Railway) e frontend em Angular com Tailwind CSS (Vercel).
Autenticação JWT, CRUD de transações, resumo financeiro em tempo real e documentação Swagger.

**Stack:** Java • Spring Boot • Spring Security • JWT • PostgreSQL • Angular 17 • Tailwind CSS • Railway • Vercel

### 🏥 Physical Med Management
Sistema desktop para gestão de vendas, produtos, vendedores e estoque, com foco em dados e relatórios.

**Stack:** Java • JavaFX • PostgreSQL

## ⚙️ Como rodar localmente

Não há dependências ou build necessários — basta abrir o arquivo principal no navegador.

```bash
# Clone o repositório
git clone https://github.com/DiegoOliveira01/diegooliveira01.github.io.git

# Abra no navegador
open index.html
```

Ou use a extensão **Live Server** no VS Code para recarregamento automático.
